Studio Avenue

A media and VFX studio’s portfolio, and a CMS shaped around the files it actually ships.

A studio that uploads its own reels
Sanity’s asset pipeline isn’t built for multi-gigabyte video, so editors get a custom Studio input that presigns a direct-to-R2 upload — 5 GB ceiling, ten-minute URLs, MIME and origin allow-lists. A publish action sweeps orphaned objects so storage never drifts from the CMS.
The homepage reel swaps in place
The hero reel lives at one fixed key, so a new upload overwrites the old file instead of accumulating. Its public URL carries a per-upload cache-buster, so browsers and the CDN pick up the change the moment it lands.
Edits they can see before publishing
Sanity’s Live Content API with draft perspectives and stega, so the team previews unpublished changes on the real page. Queries are GROQ with generated types, and images carry blur placeholders, hotspot, and crop.
Infrastructure as code, not a dashboard
Next.js runs on Cloudflare Workers through OpenNext, with the worker, bucket, and bindings declared in an Alchemy script — so the production environment is reviewable and reproducible.
